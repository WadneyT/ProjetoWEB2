# UEG Motors — frontend

Interface React + TypeScript para gerenciamento de marcas e automóveis.

## Desenvolvimento

```sh
npm install
npm run dev
```

Por padrão, a API é acessada em `http://localhost:8080/api`. Para apontar para outro endereço, defina `VITE_API_URL`.

## Verificações

```sh
npm run build
npm run lint
```
